Upstream proxies

HostPortProtocolUsernamePasswordPassword env var
Each proxy is probed every 2 s by fetching the Health probe URL (Settings) through it. SOCKS5 with username/password is supported. Prefer an env var (e.g. UP_PASS) over a stored password; stored passwords are kept in a 0600 config file and are never shown again. Use SOCKS5 over trusted networks, WireGuard or an SSH tunnel.
